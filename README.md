# Gens OP Generator Network

The Gens OP Generator Network is a lightweight, efficient Minecraft plugin designed for Paper/Spigot servers running versions 1.20-1.21. It offers a comprehensive suite of features including a generators system, islands and claiming, economy and shops, ranks and rewards, and a scoreboard and HUD. The plugin is optimized to run seamlessly on a server with 3.5GB RAM without causing lag.

## Install

1. Download the latest version of the plugin from the [releases page](https://github.com/EnderDevelopment/GensOPGeneratorNetwork/releases).
2. Place the downloaded JAR file into the `plugins` folder of your Paper/Spigot server.
3. Restart your server to load the plugin.

## Use

1. **Generators System:**
   - Place a generator block using the `/gens create <type>` command.
   - Upgrade generators using the `/gens upgrade <generator>` command.
   - Withdraw resources or merge generators with one-click actions.

2. **Islands & Claiming System:**
   - Create a private island upon first join.
   - Teleport to your island using the `/gens island` command.
   - Protect your island and manage permissions with the trust/invite system.

3. **Scoreboard & HUD:**
   - View your player information, rank, balance, and current generator level on the scoreboard.

4. **Economy & Shops:**
   - Open the shop menu using the `/gens shop` command.
   - Sell all items in your inventory with the `/sellall` command.
   - Buy and sell resources and items among players using the player shops system.

5. **Ranks & Rewards:**
   - View your rank using the `/gens rank` command.
   - Earn rewards and progress through the rank system.
